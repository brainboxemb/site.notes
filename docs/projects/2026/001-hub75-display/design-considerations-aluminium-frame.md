# Aluminium Frame Design Considerations

This page describes the main dimensions and construction choices for the aluminium frame inside the HUB75 display enclosure.

## Main Dimensions

The frame uses 20 × 20 mm aluminium construction profiles.

```text
Overall width:       840 mm
Overall height:      360 mm
Horizontal profiles: 840 mm
Vertical profiles:   320 mm
```

The overall height is formed by:

```text
20 mm top profile
+ 320 mm vertical profile
+ 20 mm bottom profile
= 360 mm
```

## Panel Mounting

The five HUB75 panels will be mounted to the frame using custom brackets.

Because the brackets are designed specifically for the display, the profile positions do not need to follow the original panel mounting-hole pattern directly.

This allows the aluminium frame dimensions to be defined independently from the panel mounting points.

## Profile Layout

The horizontal profiles extend across the full width of the frame.

The vertical profiles are mounted between the upper and lower horizontal profiles.

```text
840 mm horizontal profile
────────────────────────────
│                          │
│       320 mm             │
│    vertical profiles     │
│                          │
────────────────────────────
840 mm horizontal profile
```

## Reason for Full-Width Horizontal Profiles

The full-width horizontal profiles keep their ends accessible after assembly.

This makes it possible to insert additional sliding T-nuts later without dismantling the frame.

These T-nuts can be used for:

- Panel mounting brackets
- Additional supports
- Electronics mounting
- Cable-management parts
- Future modifications

If the horizontal profiles were mounted between full-height vertical profiles, their ends would be blocked after assembly.

## Conclusion

The current frame design uses:

```text
2 × horizontal profile: 840 mm
vertical profiles:      320 mm
profile size:           20 × 20 mm
overall frame size:     840 × 360 mm
```

The horizontal profiles remain the full-length members because this keeps the slots accessible for additional sliding T-nuts after construction.
