# Dust Collection System

This project documents the research, design and construction of a modular dust collection system for a small workshop.

The primary goals are:

- Improve dust collection efficiency.
- Reduce filter loading using a cyclone separator.
- Standardize on the OsVAC connection system where practical.
- Build a modular and expandable system.
- Document research, design decisions and implementation.

## Current Equipment

- Festool CTL 15 E dust extractor
