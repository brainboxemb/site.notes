# Project Status

This page defines the status information used throughout the projects.

The status block at the top of each project provides a quick overview of the current state of the project.

## Project Phase

| Icon | Phase | Description |
|------|-------|-------------|
| 🔍 | Orientation | Collecting information, requirements, references and inspiration. |
| 💡 | Concept Development | Exploring possible solutions and comparing different concepts. |
| 📐 | Design | Developing the selected concept into a more detailed design. |
| 🛠️ | Prototype | Building and testing one or more prototypes. |
| 🚀 | Realisation | Building or implementing the final solution. |
| ✅ | Completed | The intended result has been completed. |
| 📦 | Archived | The project is retained for reference, but no further development is planned. |

## Activity Status

The project phase and activity status are separate.

A project can, for example, still be in the **Design** phase while no work is currently being done on it.

| Icon | Status | Description |
|------|--------|-------------|
| 🟢 | Active | Currently being worked on. |
| 🟡 | Idle | No current activity, but work is expected to continue. |
| ⏸️ | On Hold | Temporarily paused, for example while waiting for parts, information or a decision. |
| ⚫ | Inactive | No active development at the moment. |
| 📦 | Archived | No further development is planned. |

## Project Status Block

Each project should start with a status block similar to:

| Property | Value |
|----------|-------|
| **Start Date** | 2026-08-07 |
| **Last Update** | 2026-08-08 |
| **Phase** | 🔍 Orientation |
| **Activity** | 🟢 Active |
| **Current Activity** | Inventory of available parts and defining the first concept |

## Dates

Dates use the following format:

`YYYY-MM-DD`

For example:

`2026-08-08`

The **Last Update** field should represent the last meaningful update to the project, rather than every small documentation edit.
