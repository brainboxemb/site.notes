# Folding Workbenches

This page contains folding workbench ideas for workshops where the available floor space is limited.

## Folding Workbench Based on Pinterest Plans

- [YouTube — Folding workbench based on Pinterest plans](https://www.youtube.com/watch?v=RdNSjDbmCuk&t=777s)

This workbench is based on plans found on Pinterest.

According to the comments below the video, the original design was adapted to create a larger work surface of approximately **60 × 120 cm**.

The workbench folds into a compact unit when it is not being used.

## Best Workbench for Tiny Workshops

- [YouTube — Best Workbench for Tiny Workshops](https://www.youtube.com/watch?v=9iJZP-6WNtg)

This design is intended for a very small workshop.

The workbench can be folded away to reduce the amount of permanent floor space it occupies.
